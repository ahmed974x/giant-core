# ADR-089: SkillSpector security shield, zero-cost data engine, profit-split calculator, AGENTS.md / CLAUDE.md

Date: 2026-10-18 · Status: Accepted (Phase 4 approved by Ahmad 2026-10-18 20:34Z, together with merging PR #20)

## Context
Ahmad asked for four things in Phase 4: a scanner that catches unsafe code in the project and in any skill or plugin before it is installed, plus an encrypted browser vault; free keyless data in THE CHAIN and the Ops Room, including a quant-implied target range next to the manual analyst entry; an interactive profit-split / high-water-mark calculator in place of the static copy-portal card; and `CLAUDE.md` + `AGENTS.md` that make the design and checks binding. The coordinator's limits still hold: no real trading, no copy-trading, no investor money.

## Decision
- **SkillSpector** (`scripts/skillspector-audit.mjs`, Node stdlib only). 13 rules: key literals, `curl | sh`, `eval`/`new Function`, process execution, XSS sinks, missing SRI, prompt-injection phrases in agent files, inline handlers, `process.env`, `localStorage`, plain `http://`, unknown hosts, `target=_blank` without `noopener`, plus a CSP check (meta present, `default-src`, no `unsafe-*`, no wildcard, `object-src 'none'`, `base-uri`, every inline script/style hash-pinned). Severity rises inside `.claude/skills`, `plugins` and `mcp`. Key literals are masked in every report. `--strict` exits 1 on critical/high; `--fix` adds `noopener`, re-pins CSP hashes and copies the rules into the Ops Room; `--fetch` adds SRI. Suppressions live in `.skillspector.json`, each with a written reason, and are listed in every report.
- **CSP on every page** (landing, Ops Room, THE CHAIN): `default-src 'none'`, sha256-pinned inline code, named `connect-src` hosts. `style=""` attributes were removed because the CSP blocks them.
- **Ops Room shield** (`#shield`): live self-check of the page (CSP, violations, SRI, handlers, noopener, secure context, plaintext keys in storage) and a file/folder scanner running the same rules in the browser; nothing leaves the browser.
- **Vault**: WebCrypto AES-GCM-256, key from PBKDF2-SHA256 600,000 rounds, non-extractable; only `{salt, iv, ciphertext}` stored; auto-lock after 5 minutes; encrypted backup/import; one click moves any plaintext key found in `localStorage` into the vault and deletes the plaintext.
- **Data engine** (all free, no keys): Ops Room adds CoinGecko global market cap and DefiLlama DeFi TVL. THE CHAIN adds a SEC EDGAR pull into HISTORICALS (10-K annual values from `companyfacts`, millions, accession number and filing date shown and linked), a digital-asset card (CoinGecko, Binance, DefiLlama), and a Quant-Implied Target Range labelled `[INFERENCE - Quant Model]`: seeded GBM Monte Carlo from historical volatility (Binance or Stooq, or manual) with zero log drift, a DCF Monte Carlo that perturbs the INPUTS assumptions, and an equal-weight pooled P10–P90, drawn against the verified analyst range.
- **`scripts/omega-data-proxy.mjs`**: SEC and Stooq send no CORS headers, so a 127.0.0.1-only proxy fetches a fixed allowlist (SEC tickers, SEC companyfacts, Stooq daily CSV), sends the SEC contact User-Agent from `OMEGA_SEC_UA`, keeps under SEC's rate limit, caches on disk and answers local pages only.
- **Profit-split calculator** on both landing pages and in the Ops Room: `fee = rate × max(0, NAV_before − HWM × (1 + hurdle))`, `HWM ← max(HWM, NAV)`. Shows net value, net profit, fee share, value before fees, current HWM, protected periods, a growth chart and a per-period table. Browser-only math; the page states that no money is accepted and no trade is copied. The copy-portal card keeps «قيد الموافقة».
- **`AGENTS.md`** (process rules for any agent) and **`CLAUDE.md`** (imports AGENTS.md and DESIGN.md). `DESIGN.md` gains a security section. CI job `.github/workflows/skillspector.yml` runs the strict scan on the UI, scripts and project skills.

## Consequences
- A PR touching the UI fails CI if SkillSpector finds a critical or high issue there. The whole-repo baseline (90 high, mostly `innerHTML` and `subprocess` in older dashboards and services) is listed in `audits/SKILLSPECTOR-REPORT-phase4.md` for later passes; it is not in the CI scope yet.
- Any edit to an inline script or style needs `--fix` to re-pin hashes, or the browser blocks the script.
- SEC needs the proxy running with `OMEGA_SEC_UA` set on the laptop. No external feed could be reached from the cloud sandbox, so live calls were tested with recorded-shape mocks; the first live run is on Ahmad's laptop.
- Nothing new trades, accepts money or copies trades.
