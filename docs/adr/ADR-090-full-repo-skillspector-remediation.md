# ADR-090: Full-repo SkillSpector remediation, 0 critical / 0 high

Date: 2026-10-19 · Status: Proposed (waiting for Ahmad's review; nothing merged or pushed)

## Context
ADR-089 added SkillSpector (`scripts/skillspector-audit.mjs`). CI runs it in strict mode only on the Phase 4 surfaces (site-landing, the Ops Room, scripts, the two project skills). A whole-repo scan on `main` at `8f7d54a` found 1 critical and 90 high findings: markup written with `innerHTML` in the legacy dashboard (`dashboard/index.html`, 23 sinks) and Newton's page (`newton/ui/index.html`, 4), seven HTML pages without a Content-Security-Policy, process starts in services, web scripts, tests and the pre-commit hook, `new Function` in an n8n test and in a vendored 3D library, env reads and two unknown hosts inside `mcp/` (where the scanner raises them to high), vendored skills from anthropics/skills, and the pipe-to-shell rule matching its own description in the ADR-089 text.

## Decision
Fix first-party code for real. Suppress only vendored third-party code and first-party process starts that a line-by-line review showed are safe, each with a written reason in `.skillspector.json`.

- **XSS sinks → DOM building.** `dashboard/index.html` gets a small `dom(tag, props, ...kids)` helper (plus `svg()` for the Fear & Greed sparkline): text goes in as text nodes, attributes through `setAttribute`, colours through CSSOM (`el.style`, `style.setProperty("--k")`). Every renderer (anomaly and whale streams, symbol buttons, health bar, screen-reader table, chart and node tooltips, Cortex providers, news mood, quant table, agents, nervous system, Brain steps, modules) now uses `replaceChildren`. Newton's page uses the same pattern (`h()`), and evidence links pass a `safeUrl()` check. Look and behaviour are unchanged (checked side by side in Chromium).
- **Strict CSP on every page.** `dashboard/{index,brain/index,mind/index,offices/index,offices/guide}.html`, `newton/ui/index.html` and `web/public/offline.html` carry `default-src 'none'`, sha256-pinned inline script and style (pinned with `--fix`), `connect-src 'self'` where the page calls its own API or `/events`, `img-src 'self' data:` (plus `blob:` for the mind map), `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`. Inline `style=""` attributes on the mind page moved to classes; the offline page's `onclick` moved to `addEventListener`. The dashboard and Newton pages get a `data:` favicon so the browser does not log a 404.
- **3d-force-graph under a strict CSP.** The vendored `3d-force-graph@1.80.1` injects an empty style element and three style sheets when it loads. Byte-identical copies sit in the mind page's head, so `--fix` pins their hashes and the library's styles are allowed without `'unsafe-inline'`. Its `new Function` code generators belong to the ngraph engine; the page uses the default d3 engine, and the CSP has no `'unsafe-eval'`. The 3D view was opened in Chromium with zero CSP violations.
- **Process starts.** `services/director00/phoenix.py` starts every process through `_run` / `_spawn`, which take a list argv, set `shell=False` and check the program against a fixed allowlist (restic, docker, node, powershell, Docker Desktop). `_run` always has a timeout. Restic snapshot ids are checked as hex before they reach `restore`, and `node` is resolved with `shutil.which`. Two new tests cover the allowlist and the id check. `services/workstation/plugin_manager.py` runs the owner's plugin with a minimal environment, so it inherits no API keys. `web/scripts/secrets.mjs` no longer goes through `cmd /c`: the clipboard is cleared with `clip` on empty stdin, Bitwarden opens with `explorer.exe <url>`, and every call has a timeout. The pre-commit hook's `git` calls get a timeout.
- **n8n test.** `n8n/test/news-sentiment.test.js` compiles each Code node with `node:vm` (`new vm.Script(...).runInThisContext()`) instead of `new Function`. It runs in the same realm, so the asserts are unchanged.
- **Hosts.** `binance.com` (trade-page source links) and `gdacs.org` (test fixture) are added to `allowHosts`.
- **ADR-089 wording.** The pipe-to-shell example in ADR-089's rule list is now written in words, so the critical rule no longer matches documentation.

## Consequences
- `node scripts/skillspector-audit.mjs --strict` over the whole repo exits 0: critical 0, high 0 (was 1 / 90). There are 25 new suppressions (34 in total), 76 suppressed findings in total, and every one is listed in each report with its reason.
- Vendored code stays untouched: `dashboard/mind/vendor/**`, the anthropics/skills folders `algorithmic-art`, `web-artifacts-builder` and `webapp-testing`, and the git-ignored esbuild bundle `mcp/omega-sentinel/server/**`. When 3d-force-graph is upgraded, the three style copies in `dashboard/mind/index.html` must be refreshed from the new file and re-pinned with `--fix`.
- The relay still sends its own, looser CSP header for the dashboard pages. Browsers enforce both policies, so the stricter meta policy decides. Tightening the header is left for a separate change to `services/relay`.
- The contrast gate (`audits/verify-contrast.mjs`) reads the OKLCH design tokens from DESIGN.md. The legacy dashboard, Newton and offline pages have no such tokens and no colours changed, so the gate does not apply to them.
- A future `RESTIC_BINARY` must be named `restic` or `restic.exe`, or Phoenix refuses to start it.
